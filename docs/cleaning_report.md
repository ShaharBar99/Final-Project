## Raw files

|---|---|
| `Pubmed-Diabetes.NODE.paper.tab.txt` | 19,717 papers, each with a class label (1, 2 or 3) and 500 TF-IDF word features |

## Actions, in order
| # | Action | Function | Removed | Left | Why |
|---|---|---|---|---|---|
| 1 | Read nodes: keep only id and label | `load_nodes` | 500 word-feature columns | 19,717 nodes | Our model uses only graph structure |
| 2 | Read edges as source -> target | `load_edges` | - | 44,338 | A cites B = edge A -> B |
| 3 | Remove duplicate edges | `remove_duplicate_edges` | 0 | 44,338 | Phase A requirement; none found |
| 4 | Remove self-loops | `remove_self_loops` | 3 (papers 10751750, 9221759, 1586783) | 44,335 | A paper citing itself says nothing about importance |
| 5 | Resolve mutual citations | `resolve_mutual_citations` | 11 | 44,324 | A and B citing each other is impossible in time; kept newer -> older, see decisions.md |
| 6 | Drop edges with unknown papers | `keep_known_papers` | 0 | 44,324 | Safety check; every edge endpoint is in the node file |
| 7 | Remove isolated nodes | `remove_isolated_nodes` | 0 | 19,717 nodes | Phase A requirement; none found |
| 8 | Final checks (report only) | `check_graph` | - | - | See below |

## Final graph
- 19,717 nodes, 44,324 edges, density about 0.000114.
- 1 weakly connected component (nothing is cut off).
- 0 directed cycles -> a DAG, consistent with "citations only go back in time".
- Max in-degree 171, max out-degree 130.
- 2,047 papers are never cited; 15,840 papers have no outgoing citation. The second number is large because this dataset only contains references that point to papers inside the dataset; it is a property of the sample, not an error.

## What we did NOT do
- No temporal validation by year: the dataset has no dates.
- No node sampling: all 19,717 papers are kept.
